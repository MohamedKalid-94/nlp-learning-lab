# NLP Learning Lab

A structured, hands-on journey through NLP — from classical text processing
to modern Transformers to a full applied GenAI-adjacent project.

## Structure

| Phase | Topics | Focus |
|---|---|---|
| [Phase 1: Classical NLP](./Phase-1-Classical-NLP) | 1-10 | Preprocessing, tokenization, TF-IDF, classification |
| [Phase 2: Modern NLP](./Phase-2-Modern-NLP) | 11-21 | Word2Vec, Attention, Transformers, BERT, GPT |
| [Phase 3: GenAI](./Phase-3-GenAI) | 22-30 | Embeddings, RAG, Agentic AI |
| [Support Ticket Project](./Support-Ticket-Project) | Applied | All 10 classical topics combined into one working system |

Each topic folder contains an examples and a working
Python implementation (`main.py`), verified and run against real output.

## Capstone Project

[Support Ticket Intelligence System](./Support-Ticket-Project) — a full
pipeline (preprocessing → NER → classification) applied to a real 100-ticket
dataset, achieving 70% classification accuracy with documented limitations.
